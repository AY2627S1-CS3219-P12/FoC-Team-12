# FoC Feature Analysis

Follow the reading path in [root AGENTS.md](../../../AGENTS.md). Inspect relevant source/tests,
backlog/design evidence and published contracts; use the service checklist only to scope an
iteration. Report missing scaffold or environment evidence.

Present one brief covering actor/outcome, owning service, acceptance scenarios, data/API/event/UI
effects, dependencies/exclusions and unresolved decisions. Apply root contract gates and the
owning service's invariants. Distinguish existing behavior from proposed decisions.

Wait for explicit approval before editing product files, tests, shared configuration or workflow
artifacts. Existing approval of this brief is sufficient; request renewed approval only for a
material scope/contract change or unresolved decision.
